Findings
  • Leiden-CPM finds no admin/play split: at every resolution it returns a single dense core plus singletons (largest cluster 61–21 nodes). The @-network is one integrated community, not two.
  • The modularity objective surfaces 4 soft communities (Q=0.241), but they are not real structure: against a degree-and-weight-preserving null (Q=0.379±0.015) the observed Q sits below chance (z=-9.14, p=1.0 — no more than chance). The graph is less clustered than a random graph with the same degrees and tie-strengths — i.e. genuinely integrated, which agrees with the CPM monolith result.
  • Such soft grouping as exists is founder-tenure, not admin-vs-play: community c1 holds 12 of the ~20 founders and by far the highest message rate (213/head), while the largest community c0 is the broad roster (50 roster members). Play (attendance) is spread evenly across all communities — nobody is walled off from the game.
  • [ASSUMPTION] Communities computed on the undirected, weight-collapsed graph (direction matters less for bloc membership). Null uses the Chung–Lu expected-degree model; a stub-matching configuration model gives the same qualitative envelope.
Method, data & caveats
Leiden via leidenalg on the undirected, weight-collapsed @-mention graph (n=136). CPM (resolution 0.1–1.0, 15 restarts each) returns a monolithic core at all resolutions — reported as-is. Modularity objective (40 restarts, best quality kept) gives 4 communities, Q=0.241 (weighted modularity). Null: 300 degree-preserving random graphs (nx.expected_degree_graph, Chung–Lu); because the observed Q is weighted, each rewire is given the observed edge-weight multiset (randomly permuted) and scored with the same weighted modularity — a like-for-like test (the earlier build compared a weighted Q to an unweighted null, which inflated z). Observed Q vs the null distribution (mean 0.379, sd 0.015; 5–95% band 0.352–0.404); z and empirical p reported. Substrate analysis/gA_graph.py; script analysis/gA_nq2.py.
